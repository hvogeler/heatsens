Implementation Notes

  • Display: 320×170 px, dark background, LVGL 9.x
  • Temperature distinction (no text labels): color (white vs teal), size (large vs smaller), position (left vs right, or top vs bottom) make it immediately obvious which is current and which is target
  • Heating states (visual, minimal text):
    • Option A: top status strip + center dots — amber/red color coding
    • Option B: left-edge glow bars — inspired by heatctrl Option D. Most minimal: zero text for status
    • Option C: progress bar itself conveys heating state through color and glow. Small dot+label row for clarity
  • Fonts needed: Rubik_Medium_48 (current temp), Rubik_Regular_36 (target temp), montserrat_16 (labels), montserrat_10 (meta)
  • Color palette: #f0f0f0 (current temp), #4ecdc4 (target temp), #daa520 (requested), #e83030 (heating), #333-#666 (inactive/structure)
  • LVGL features: flex/grid layout, border + shadow styles for glow, bg_opa for tinted backgrounds, lv_bar for Option C's progress bar
  • State variants shown: Heating (both active), Requested-only (waiting for actuator), Idle (both off)
